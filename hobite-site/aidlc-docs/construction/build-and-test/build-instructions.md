# NVIDIA Research Hub Build Instructions

1. Run `npm run research:nvda:data` from `hobite-site` to refresh SEC and market data.
2. Run `npm run build` from `hobite-site`.
3. Run `npm run build` from the SVIM repository.
4. Confirm the Hobite English and Chinese routes and the SVIM `lang=en` and `lang=zh` variants render.
